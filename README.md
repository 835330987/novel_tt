## ✨ Obsidian优化亮点

### 1. MOC内容地图系统

- **[[00_首页]]** - 总入口，快速导航到所有模块
- **[[人物MOC]]** - 人物关系、冲突矩阵、分组索引
- **[[世界观MOC]]** - 设定分类、伏笔关联、学科索引
- **伏笔管理**作为剧情MOC

### 2. 双向链接

- 每个人物有独立笔记，互相链接
- 章节内容链接到相关人物、伏笔、设定
- 知识图谱自动展示人物关系网络

### 3. 标签体系

- `#人物/主角`、`#人物/反派`、`#人物/村民`
- `#伏笔/已埋`、`#伏笔/已露`、`#伏笔/已爆`
- `#章节/草稿`、`#章节/已确认`
- `#设定/规则`、`#设定/地理`等

### 4. 模板系统

- 使用`Templates/`下的模板快速新建人物/章节
- 自动带YAML元数据、标签、双向链接占位

### 5. YAML前置元数据

- 所有核心文件带tags、创建时间、状态等元数据
- 可配合Dataview插件做查询和仪表盘

## 🚀 使用建议

1. **从首页开始**：打开`[[00_首页]]`作为起点
2. **新建人物**：用`[[Templates/人物模板]]`复制，在Characters/下创建新文件
3. **新建章节**：用`[[Templates/章节模板]]`复制，在Content/章节/对应卷下创建
4. **添加伏笔**：在`[[伏笔管理]]`中登记，并在相关章节和人物笔记中双向链接
5. **利用图谱**：打开Obsidian知识图谱视图，可视化人物关系网络
6. **标签搜索**：点击标签快速筛选同类型内容

## 🔌 推荐插件

为了更好体验，建议在Obsidian中安装：

- **Dataview** - 数据查询，自动生成列表/表格（首页预留了dataview代码块）
- **Templater** - 更强大的模板功能
- **Graph Analysis** - 图谱分析
- **Tag Wrangler** - 标签管理
