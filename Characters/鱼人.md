# 鱼人

#人物/主角

## 基本信息

| 项 | 内容 |
|---|---|
| 代号 | 鱼人（人称"话痨鱼人"） |
| 明面身份 | 外部调查机构"异常事件调查员" |
| 暗线身份 | [[米老头]]旧实验的幸存者/被抛弃者 |
| 外貌 | 瘦长，肤色偏冷白，眼睑常半垂如鱼；总穿一件湿痕未干的灰风衣（实为算力屏蔽织物） |
| 性格 | 话痨。嘴不停，脑子更不停；见什么说什么，说着说着就把真相"说"了出来。是事件的金牌解说员，常在叙事中充当旁白——读者靠他的碎嘴子理清线索 |
| 行事风格 | 看似随意贫嘴，实则每句都在试探、记录、推理；用絮叨降低他人戒心，再一刀见血 |
| 暗黑三人格 | 马基雅维利中等（善以言语操纵场面），精神病态低，自恋中（享受"我早说过了"的优越感） |
| 罪业 | 曾在另一试验区为求生存，出卖同伴换算力配额——这是他受洗也抹不去的底色（残影最重的一条）；他用喋喋不休的话掩盖这份罪疚 |
| 动机 | 找[[米老头]]要一个"答案"：当年为何救他，又为何抛弃他？救赎是否只是另一种利用？ |
