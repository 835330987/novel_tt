## 货币体系（2026-10-06 作者终定，写稿一律照此，旧模型全部作废）
- **钱**＝日常货币（吃饭/住店/工钱/酒水/房租/草海拾得）。
- **穗**＝**不是货币、不是零钱、不是最低级货币**。是"钱换道"时**被上头抽走的那道损耗**，只落账上、握不到手里。官价三百钱一道、黑市二百八，差的二十即穗。
- **道**＝交易筹码，**只有持牌处所（「太平门」兑点）才给换**，用于「以道生道」；道不当饭吃、换不回钱。
- **根**＝本命，不可交易，只能押/断。
- 路径：**钱 →〔换道，抽穗归上头〕→ 道 →〔亏光〕→ 押根 → 根断人亡**；「进以钱，博以道」＝双重剥皮。
- 旧提法一律作废：道穗／道穗根／10穗=1道／"穗=绿豆零钱"／草海长穗。新提法：钱道／钱穗道根；腰斩＝道减半；断头铡＝道七成没；红阶存道；绿陷吞钱→道→根；镰傀只扣道；草海长"钱"（长钱天／磨钱天／枯钱天）。
