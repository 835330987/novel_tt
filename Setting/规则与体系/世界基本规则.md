# 世界基本规则

> **叙事揭示原则**：本文档定义青原运转之底层规则。所有金融概念（爆仓/杠杆/熔断/收割）前期皆以「道穗根/等级/腰斩/断魂刀」等股市修仙江湖语呈现，后期方随主角认知提升逐步揭露本质。一切规则设定须服务于此反转。

## 一、三道三轨体系

| 类型     | 别称（叙事用）               | 性质     | 获取方式                                                 |
| -------- | ---------------------------- | -------- | -------------------------------------------------------- |
| **穗**   | 绿豆子/零钱/碎银子           | 流通货币 | 小赌赢取、日常劳动、草地拾得（每天长几颗）                 |
| **道**   | 金丸子/本金/存款/身家        | 高值货币 | 大赌赢取、大额交易、地产收租、抬轿人/对倒仙人的俸禄        |
| **根**   | 本命根条/红骨头/三寸条       | 根本之物 | **生而携带，一人一根，独一无二不可再生**                   |

- 消耗顺序铁则：**先花穗 → 穗尽用道 → 道尽抽根 → 根断人亡**（不可逆）
- 官方汇率：10穗 = 1道。黑市汇率波动大，押根借道时1道要还3道起。
- 穗与道可以自由交易。**根不可交易**，只能「抵押」（借根局合同条款）或「自断」（自愿押出）。

## 二、三道限量与分配规则

青原总道总穗有定数，总根=总人数（一人一根）。分配原则：**赢家通吃，天尊先拿，老祖后拿，散修最后吃渣。**

| 层级 | 分成比例 | 说明 |
|---|---|---|
| 掌局天尊/算天宗 | 总流通的50% | 无论谁赢谁输，这部分每日自动流入禁区 |
| 御盘老祖/御线道君 | 20% | 各局台费+技能消耗+对倒获利 |
| 量枢真君/对倒仙人/抬轿人 | 15% | 中层分成，围猎分食 |
| 镰傀 | 5% | 量化收割所得，天尊额外发「维护穗」 |
| 散修+缠论祖师 | 10% | 韭菜池：互赌互吃，偶尔赢老祖一点，最终还是会流回上层 |

### 断根回收规则

- 一根断掉 → 自动流入禁区 → 算天宗提炼 → 变成掌局天尊发动一字断魂刀的「刀条」（消耗品）。
- 所以天尊最爱公开处刑：**每根断掉的根，都是他们下一把刀的原料。** 白色指数越高，天尊刀越多。

## 三、三重铁则

青原无法律，但有三重铁则。铁则之间的模糊地带，就是天尊灰色地带，也是主角能钻的空子——剧情引擎。

| 层级 | 来源       | 性质                 | 典型覆盖范围                                               |
| ---- | ---------- | -------------------- | ---------------------------------------------------------- |
| 最底 | 根的本质   | 物理规则，不可推翻   | 一人一根不可再生、断根必枯壳、道穗可以伪造（但很少成功）根不行 |
| 中层 | 天尊规矩   | 可解释可操纵         | 「开市禁技能」「游戏愿赌服输」「押根必还」「等级低者不可攻击等级高者」 |
| 最上 | 天尊契约   | 当前权力平衡产物     | 围猎团不碰守护者地盘、借根铺不追天台债、章盟主的中立豁免权     |

### 最高准则

> **在草原里，你可以赢九次，但只要输一次，就能让你万劫不复。**

在此准则下，天尊可以在三重铁则的模糊地带做到：根的本质管不着、天尊规矩没明禁、天尊契约模棱两可的事情。**天尊设局的手法、守护者钻空子的手法，全在这灰色地带展开。**

**典型灰色地带案例**：
- 规矩说「开市禁技能」——但镰傀算「器械」不算技能？所以闭市后镰傀可以继续割。
- 规矩说「等级低者不可攻等级高者」——但散修用**群攻**（几百个散修一起围一个抬轿人）算不算？老炮的旧围猎团当年就靠这个吃过老祖。
- 规矩说「押根必还」——但凯哥当年的合同里，「还」字后面有个极小的字体「天尊认定同等价值之物亦可」。天尊认定凯哥的命值这个，凯哥就必须死。

## 四、修仙等级与权限规则

### 等级权限对照（10阶）

| 阶 | 称号         | 攻击权限                              | 豁免权限                             | 特殊权限                                   |
| -- | ------------ | ------------------------------------- | ------------------------------------ | ------------------------------------------ |
| 1  | 散修         | 无技能，只能游戏互斗                  | 无。被任何技能波及都全额承受          | 可自由进入散修大厅                         |
| 2  | 缠论祖师     | 无技能，但可「看破」技能效果           | 被攻击时可预判躲避（但不能挡）        | 可进贵宾厅观摩；可在散修中开「授道局」收徒 |
| 3  | 抬轿人       | 初级技能（假突破）                    | 被同等级技能攻击伤害减半              | 可进贵宾厅参局；可雇佣散修当轿夫           |
| 4  | 对倒仙人     | 中级技能（对倒、量骗）                | 被低于自身等级的技能豁免             | 私局常客；可开对倒局自玩                   |
| 5  | 镰傀         | 群体腰斩（弱化版），日夜不停          | 物理伤害免疫（因为是器）              | 不进禁区；不被任何等级主动攻击（天尊之器） |
| 6  | 量枢真君     | 高级技能（仙人指路、量锁）            | 散修/缠论祖师的群体攻击免疫           | 私局主持；可调控某局的穗道流量开关         |
| 7  | 御线道君     | 顶级技能（腰斩、断头铡、假突破完整版）| 抬轿人以下所有技能免疫                | 自有局主持；章盟主半步老祖——可攻御盘老祖    |
| 8  | 御盘老祖     | 一字断魂刀（弱化3轮）                 | 对倒仙人以下所有技能免疫              | 围猎局总指挥；可收抬轿人/对倒仙人为部下     |
| 9  | 算天宗       | 预判技能（顶底背离、预判断魂刀）      | 御线道君以下所有技能免疫；禁区豁免    | 禁区常驻；可与掌局天尊直接沟通             |
| 10 | 掌局天尊     | 全部技能完整版（断魂刀9轮、天地板）   | 一切技能免疫。**全青原唯二没有根的存在**（另一个是白衣人）| 制定规矩；发动一次天地板，白色指数疯涨10格 |

### 越级攻击铁则

- 同等级：可互相攻击，伤害正常。
- 低1级：高等级对低等级伤害×1.5；低等级伤害×0.5。
- 低2级以上：高等级伤害×3；低等级几乎无伤害（不破防）。
- **腰斩的等级判定**：只能波及比发动者低2级的人。所以章盟主（御线道君）能腰斩散修和缠论祖师（低2/1级），但不能腰斩抬轿人（低0级）。这给了缠论祖师晋升抬轿人的直接动力——升一阶，就不被腰斩了。

## 五、技能使用时段与熔断规则

| 时段 | 允许技能 | 原因 | 熔断机制（隐藏规则，散修不知道） |
|---|---|---|---|
| 开市（日出敲钟） | 全部禁止 | 怕吓走新散修，白色指数开盘点位不稳 | **开市熔断**：如果有人硬放技能，龙门大厦所有游戏自动暂停一刻钟，庄家损失惨重。所以没人敢在开市放。 |
| 盘中（白日） | 腰斩、假突破、仙人指路、对倒、量骗、镰傀群体割 | 围猎密集期，天尊主战场 | **盘中熔断**：半刻钟内断根超过100根，白色指数跳涨3格以上，触发临时熔断（暂停游戏），防止散修恐慌跑路。 |
| 收市（日落） | 镰傀自由割，其他技能威力减半 | 散修清场，夜盘预热 | 无熔断 |
| 夜盘（夜晚） | 全部技能可放，包括一字断魂刀完整版 | 公开处刑时段，天尊收割最狠 | **无熔断**。夜盘断多少根都不停。这也是为什么天台「晚上开门」——最刺激最危险的时刻。 |
| 闭市（深夜） | 全部禁止 | 清理时间，断根回收去禁区做刀条 | 无熔断（反正没人玩） |

### 「开市闹出人命不吉利」的真相

不是迷信。是**开市熔断**会让天尊们每天少赚一大笔——他们约好了互相监督，开市谁放技能，谁赔当天全楼台费。

## 六、白色指数规则

### 官方说法

> 白色指数 = 今日龙门大厦总道流入 / 基准值 × 100

### 真相（后期揭露）

> **白色指数 = 今日新断根数**
> 每根红条被踩白→白色指数+1。庄家赚的道穗是暗地的，白色指数是给全青原看的「晴雨表」——实际上就是「死亡计数表」。

| 指数区间 | 对应状态       | 天尊行为                                     | 散修反应                      |
| -------- | -------------- | -------------------------------------------- | ----------------------------- |
| <50      | 「熊市」       | 放饵放水，抬轿人拉红阶造「小涨」，引散修入场  | 观望，不敢下注                |
| 50-80    | 「正常」       | 正常围猎，腰斩零散放，稳步收割               | 积极下注，觉得自己也能红      |
| 80-95    | 「疯牛」       | 红阶存穗暴涨，仙人指路连发，制造暴富幻觉      | 借根押房，梭哈跳台            |
| >95      | 「高危/股灾」  | 一字断魂刀批量放，天地板连开，集中收网        | 散修大面积断根，恐慌蔓延      |

## 七、红阶绿陷规则

### 红阶（看涨·阳线）

- 龙门大厦顶层电梯出来后的最后两层楼梯。
- 通体赤红，由实体红色**根条状物**堆叠——每阶的「存穗/存道」，就来自之前摔下去那些人的道穗（用韭菜的尸骨垒上涨台阶）。
- 阶与阶空隙宽窄不一（跳空缺口）。空隙越宽，存穗越厚。
- 登红阶不可回头——庄家有暗手，回头者70%几率直接脚滑掉绿陷。
- 失足坠落：先扣穗扣道，高度超过8层根条，直接断根概率50%。

### 绿陷（看跌·阴线）

- 龙门大厦周围、草海深处、红阶楼底，无处不在。
- 表面正常草地或地板，踩空后绿色液体翻涌——液体内有无数被啃干净的白色断根（套牢盘残骸）。
- 吞噬顺序：穗→道→根，每3个呼吸吞一级，越挣扎吞越快（×2速度）。
- 可被拉出来，但拉人者要消耗等量道（同归于尽式救人）。
- 隐形绿陷：和正常地面肉眼无差别。天尊专用阴招，专门坑缠论祖师（祖师画线觉得这里安全，一脚下去，全埋了）。

### 横盘草海

- 龙门大厦外主体，一望无际平淡草地。
- 每走一步扣1穗，穗完扣道。
- 无参照物，方向全凭感觉。99%的人在绕圈，道穗耗尽变枯壳。
- 每天日出时，庄家会放1个「出口谣言」（东边有出口/西边有近路），引导散修往隐形绿陷集中处走。

## 八、根断三途

| 状态     | 触发条件               | 后果                                                                   |
| -------- | ---------------------- | ---------------------------------------------------------------------- |
| **半枯** | 根有裂缝但未断（被腰斩震裂/绿陷吞噬过半） | 痴呆健忘，行动迟缓，可勉强劳动。**再被腰斩一次裂缝必断。**               |
| **枯壳** | 根完全断裂             | 无思想无记忆，行尸走肉。被扔出城外草海/龙门大厦最底层杂役（擦红阶拖尸体）。 |
| **极枯** | 根已断+仍欠道（借根局） | 意识尚存但身体不受控，被强制劳动「还根」——永无止境。比枯壳还惨。         |

### 断根回收流向

> 断根 → 闭市时被拖走 → 禁区算天宗提炼 → 压成「刀条」→ 掌局天尊/御盘老祖发动一字断魂刀时消耗
> 每断9根，提炼1根刀条。所以一字断魂刀9轮，刚好消耗1根刀条。

## 九、守护者豁免规则

- 苏晓「天台来帮您」享受有限豁免：
  - **天台范围内，借根铺不得追债。**（笑面虎不能进天台抓人）
  - **天台范围内，围猎/技能不得主动对顾客发动。**（老祖不能在天台上对散修放腰斩）
  - 但豁免只及天台大门内一步——出了天台门，围猎、腰斩、断魂刀，随便来。
- 豁免的代价：
  - 每月向白衣人上交「保护道」（逐月递增，第一章交100道，第二章就是300道）。
  - **庄家有权随时在天台举办公开处刑（含一字断魂刀）**，苏晓不能阻止，必须旁观。这是豁免最大的漏洞——不能对顾客放技能，但可以对「处刑对象」放，处刑对象不算「顾客」。
- **致命条件**：天台阵营任何一人**破戒（主动参与游戏/主动发动技能/放贷赚道）**→豁免自动失效→天台所有人立刻成为围猎目标，所有技能可在天台随意放。
- 这就是苏晓立三条规矩的真实原因——不是道德洁癖，是**生死存亡的开关**。
