# 体系

> **叙事揭示原则**：本文件所述博弈机制，前期以「道穗根/技能/等级」之修仙江湖语呈现；「K线/杠杆/爆仓/量化」之本质，随剧情推进逐步揭露。前期读者只觉修仙厮杀残酷，后期方惊觉——每一次腰斩，都是一次50%跌停。

## 〇、体系总纲

青原一切博弈，底层皆为**道穗根流转与等级碾压**。散修见游戏，缠论祖师见形态，御线道君见收割——掌局天尊见的，只是白色指数下一个数字。

体系分三脉：
1. **流通之脉**——道穗根运转：三级货币、消耗顺序、断根回收。
2. **博弈之脉**——基础游戏+高级技能：6种游戏对6种K线，5种技能对5种收割手法。
3. **等级之脉**——十阶操盘手体系：散修→天尊，吃别人升自己。

## 一、道穗根流通体系

### 1. 穗（绿色小球·零钱）

#### 形态
绿豆大小，圆润光滑，通体嫩绿。丢在地上叮一声响，和普通绿豆比，就是更沉更亮。

#### 产出
- 草地自然生长：青原肥沃处，每日一颗散穗可拾。
- 小赌赢取：散修大厅的猜心、走草海、低阶跳台，赌注都是穗。
- 劳动所得：擦红阶（1天5穗）、拖枯壳（1拖3穗）、后厨打杂（1天4穗）。

#### 消耗（日常）
| 项目 | 价格（穗） |
|---|---|
| 一顿粗饭 | 3 |
| 天台特调一杯 | 10（成本2，黑心暴利） |
| 散修大厅小赌1局 | 5起 |
| 龙门大厦外围住宿1晚 | 8 |
| 天台住宿1晚（庇护价） | 1 |

#### 汇率
10穗 = 1道（官方龙门大厦兑点处）。黑市：11~13穗 = 1道。借根铺抵押换穗：1道 → 只给你7穗（扣手续费+首息）。

---

### 2. 道（黄色小球·本金）

#### 形态
龙眼大小，半透明，内有金丝纹路在光下流转。温润，握在手里有暖感。大户揣在怀里，缠论祖师用锦袋装。

#### 产出
- 大赌赢取：贵宾厅围猎局、跳台红阶高阶、私局对倒，赌注都是道。
- 大额交易：卖房产、卖肥田（日产2穗的草地1亩=5道）、卖女儿/卖儿子（真人抵押，视年龄10-50道不等）。
- 俸禄：抬轿人月薪2道，对倒仙人单局抽成。
- 借根局：押根借道——1根最多借100道，还时要还300道（利滚利）。

#### 消耗（大额）
| 项目 | 价格（道） |
|---|---|
| 普通散修家庭全部身家 | 10~30 |
| 围猎局入场费 | 50起 |
| 龙门大厦贵宾厅1晚卡座 | 20 |
| 借根局100道，3天免息，第4天起翻倍 | - |
| 发动技能·腰斩 | 3 |
| 发动技能·一字断魂刀（弱化版3轮） | 1（别人的根提炼的刀条） |
| 每月天台保护道 | 100（逐月递增） |

### 3. 根（红色长条·本命）

#### 形态
三寸长，骨节状，通体血红，表面有细密的纹路——**每根的纹路完全不同，像指纹，是身份标记**。
每人胸口气海位置，生而携带一根。无法取出（除非你死了/断了/押在借根局）。
修为越高的人，根越粗越长，纹路越密。掌局天尊——据说没有根。

#### 「根纹」身份系统
- 借根局按根纹签合同：你的根纹被拓印在合同上，到期还不上，借根铺按纹抽根。
- 公开处刑抽根：白衣人一眼认根纹，不会抽错人。
- 凯哥遗物**根牌**：凯哥跳红阶前，把自己根刮下一小块，刻在牌子背面。这小块根屑，就是他在算天宗机房的「后门密钥」——因为算天宗的权限识别，认根纹不认人。

#### 根的价值（不可用道穗量化，是无价的）
- 1根 ≈ 你的寿命（断了减寿/直接死）
- ≈ 你的自由（押了借根局=成奴）
- ≈ 你的身体（借根局合同「身体一件」=抽根时顺便取器官）
- ≈ 你的家人（家人连坐条款：你根断了，家人根自动裂开半，你还不上，家人跟着断）
- ≈ 算天宗的「刀条原料」（9根=1刀条=1次一字断魂刀完整版）

#### 断根瞬间（现场描写参考）
> 胸口猛地一缩。三寸红条从气海浮出来，在空中发出「咔」的一声脆响，像被人用手掰断。断口处冒白烟，红条瞬间褪色变白——白得像纸，像白色指数上的一个点。白得刺眼。然后变成粉，一吹就散。
> 人倒下了。眼睛还睁着，但里面什么都没了。

## 二、借根局（杠杆配资）完整体系

### 借根铺柜台（笑面虎的生意）

柜台前永远排长队。笑面虎笑眯眯坐台，后面墙上八个大字——
> **「有根押根，无根押人；三日免息，利滚利翻。」**

### 借根合同条款完整陷阱表

| 条款（表面） | 实际内容（笑面虎解释给你听的版本） | 真正的坑（签了才知道） |
|---|---|---|
| 「抵押本命根壹根」 | 最后还不上才抽根，放心 | 逾期第1天抽穗，第3天抽道，第7天直接抽根——不等你真的还不上 |
| 「三日免息」 | 前三天不扣利息，福利 | 第4天利息=本金×100%，第5天在这个基础上再翻 |
| 「自愿条款」 | 你自愿借的，别耍赖 | 你敢闹，笑面虎直接按合同叫围猎团上门，按根纹抽根 |
| 「家人连坐」（小字） | 没提 | 你根断时，合同自动生效：你直系亲属每人根自动裂半，若还不清，一并抽走 |
| 「天尊认定同等价值」（极小字体，放大镜才看得到） | 没提 | 你觉得你还了300道=还了。天尊说今天道贬值了=你还欠200。天尊认定=最终解释。凯哥就是死在这一条。 |
| 「断根归借根铺所有」 | 没提 | 你根断后，尸体归笑面虎→笑面虎卖禁区算天宗做刀条→再赚一笔 |

### 杠杆倍率与爆仓线

| 你押的根 | 借你的道 | 还不上→抽根线（你输多少道就抽根） | 爆仓隐喻 |
|---|---|---|---|
| 仅穗 | 10道（信用借） | 输10道→抽你道，道完抽你家人穗→还不上才抽根 | 无抵押信用贷，爆仓线极高，死得慢但痛苦 |
| 1颗道 | 10道（10倍杠杆） | 输1颗道→10倍赔=要还10→你本来就没道了→直接抽根 | 10倍配资，一个跌停爆仓 |
| 50颗道 | 500道（10倍） | 输50道→直接抽根 | 大资金配资，跌10%直接强平 |
| 直接押根 | 100道（最高额度） | 到期不还→抽根。期间任何游戏全输→提前抽 | All in，满仓杠杆，归零跳楼 |

## 三、基础游戏体系（6种）

前期散修视角：这是赌运气、赌人心的游戏。
后期（作者内部）：每种游戏对应一种K线形态，收割逻辑完全对应。

| 游戏名 | 对应K线 | 规则 | 收割点（庄家暗手） | 首次出现 |
|---|---|---|---|---|
| 跳台（红阶） | 跳空高开/低走 | 一阶阶往上跳，赚穗道，失足坠绿陷。不可回头。 | 空隙越往上越宽，倒数第二阶庄家偷偷加宽50%，90%的人在这掉。 | 集1红阶 |
| 猜心（三盏灯） | 十字星 | 红绿白三灯对选。红吃绿、绿吃白、白吃红。同色→翻倍→下一轮。可中途认输（半损）。 | 庄家在灯座装温度控制器：红灯热、绿灯凉。对手摸温度就知道你选啥。哑看破这个被割舌。 | 集7帮年轻散户 |
| 走草海 | 横盘震荡 | 定向走，每步扣穗，先出者分所有失败者道穗。不许停不许跑不许回头。 | 庄家每天放谣言引向隐形绿陷；底部藏量锁加速扣穗；99%绕圈。 | 集9主角草海 |
| 围猎四步曲 | 建仓→洗盘→拉升→出货 | 放饵（饵手故意输）→拉扯（让猎物赢几把膨胀）→赶场（引向死局）→收网（猎物全输变枯壳） | 围猎团成员5-7人，猎物2-3人，围猎成功率>95%。猎物在第二步已借根押根。 | 集5大户围猎 |
| 借根局 | 融资融券/配资 | 押押押，借借借，赢翻倍，输抽根 | 合同条款6大陷阱+家人连坐+天尊认定条款 | 集2公开处刑者欠的 |

| 顶背离/底背离 | 算天宗专属 | 「算天宗吐盘——顶背离！大家快逃！——不对！是假的！」 | 算天宗公布一个信号（顶=要跌/底=要涨）。缠论祖师看见了立刻操作。结果实际走势完全相反。祖师当场懵→被套。 | 1道（算天宗内部消耗） | 技术指标背离陷阱。庄家画线画指标骗技术派。缠论祖师天敌技能。 |
| 天地板（终极技能） | 掌局天尊专属 | 「天尊震怒——天地板！」 | 当天内：先把某局拉到全红（红阶连亮，存穗×10）→散修全冲→瞬间全部变绿陷到底。当天参与的所有人，90%根断。白色指数直接跳涨10格。 | 9根刀条（81断根提炼） | 当天涨停→跌停。天地板。A股散户终极噩梦。 |

### 技能使用注意（作者写作指南）
- **触发语一定要喊出来**。不要只写「他发动了腰斩」，要写「章盟主发动了技能·腰斩！」——这是爽感核心。
- **技能前一定要有铺垫**：章盟主出现→散修恐慌摸胸口根→然后才喊技能。
- **技能效果要写个体（小屁视角）的体验**：不是写「散修道穗减半」，是写「小屁手里刚领的5穗工钱，瞬间变成2穗半，旁边老缠论祖师的锦袋'哗啦'一声瘪了一半，他脸瞬间白了；小屁自己胸口的根，'嗡'地震了一下，像被人敲了一锤子——低头看，一条细缝出现了。」
- **技能要对应章末大钩子或中段高潮**：腰斩放在中段情绪点，一字断魂刀放在章末高潮或次高潮。
