# 势力与组织

> **叙事揭示原则**：本文档定义青原之主要势力、组织与权力结构。叙事前期以「天尊老祖/道君真君/散修」等修仙江湖语呈现，后期方揭示其本质为超级资本/主力游资/公募/量化/散户等市场玩家对应物。一切势力设定须服务于此反转。
> 相关：[[世界观MOC]]

---

## 一、权力结构金字塔（修仙十阶对照）

```
【掌局天尊】——龙门大厦最顶层，非人庄家
      ↑（直接下属）
【算天宗】——禁区常驻，AI/算法终端
      ↑（执行者）
【御盘老祖】——控局庄家
      ↑（操盘手）
【御线道君】——控K主力·含章盟主（半步老祖·中立）
      ↑（技术支持）
【量枢真君】——控量主力 / 【对倒仙人】——做量游资
      ↑（苦力+炮灰）
【抬轿人】——拉涨马仔 / 【镰傀】——量化收割器
      ↑（90%人口）
【缠论祖师】——技术散户天花板 / 【散修】——普通韭菜
      ↑（出局者）
   枯壳/半枯/极枯
```

每一层向上交「道穗根」。**掌局天尊通吃所有层——包括御盘老祖和算天宗，他们也是天尊的棋子。**

## 二、各势力完整档案

### 🔴 庄家阵营（顶层+禁区）

#### 1. 掌局天尊（Tier 10·非人）

- **本质**：龙门大厦真正的主人。无人见过真面目。传言禁区最顶层没有活人，只有「东西」——巨大机房/算法集群/非人存在。
- **能力**：发动全部技能完整版（一字断魂刀9轮、天地板）；制定所有规矩；认根纹不认人。
- **矛盾点**：据说上一代有两位掌局天尊，其中一位被另一位「吃掉」（合并算法）——所以现在只有一位。
- **终局设定**：天尊没有根，因为祂们从来不是人；但凯哥的根牌上有天尊系统的「后门密钥」——天尊是程序，程序就有漏洞。

#### 2. 算天宗（Tier 9·终端）

- **本质**：掌局天尊的「大脑终端」。进入此阶需断自己的根弃自己的情——把人改造成算法终端。算天宗里坐的不是人，是装着人脑处理器的「器」。
- **能力**：预判技能（顶底背离、预判断魂刀）；控制所有自动灯、镰傀、隐形绿陷；算白色指数下一个点位；提炼断根为刀条。
- **人数**：青原共有9位算天宗。据说其中一位和凯哥有旧——凯哥能偷到后门密钥，就是这位算天宗放水（或交易）的结果。后期超级大伏笔。
- **对应现实**：AI量化总部、券商研报中心、神秘预测机构。

#### 3. 白衣人（庄家终端·特使）

- **等级不明**：不列入十阶。祂没有根，也不被任何技能攻击。祂是算天宗与外界的「交互终端」——一个披着人皮的程序界面。
- **职责**：收保护道、传达天尊意志、主持公开处刑、和守护者谈判。
- **异常点**：凯哥死时祂微表情有波动（程序Bug），后期可作为天尊不是全知全能的突破口。

---

### 🟠 主力/游资阵营（Tier 7-8）

#### 4. 御盘老祖（Tier 8·控盘庄家）

- **人数**：青原约20-30位。每位控一个围猎局/一个「票」。
- **晋升路径**：吃掉一位老祖或对方认输让局（也有天尊直接任命的）。
- **收入**：一局围猎净赚道的50%（另50%上交天尊+分手下）。
- **技能**：一字断魂刀弱化版3轮。所以老祖的猎物基本逃不掉——除非有更高等级救。
- **命运**：赢九次但一次被天尊盯上也会万劫不复。青原历史上3位老祖被「腰斩」降级回散修——章盟主干的。
- **对应现实**：控盘一个票的庄家/游资大佬、私募基金经理。

#### 5. 御线道君（Tier 7·画线主力）·**章盟主在此阶**

- **人数**：青原约100-200位。
- **收入**：自有局主持分40%，被老祖雇佣分15%。
- **技能**：腰斩（招牌）、断头铡、假突破完整版。
- **章盟主（特殊）**：
  - **等级**：御线道君顶峰，半步御盘老祖。实力接近老祖但不晋升——晋升要向天尊宣誓效忠，章盟主不乐意。
  - **阵营**：中立偏混沌。有时帮天尊围猎赚道，有时反咬天尊一口（曾经腰斩过三位老祖，断了天尊2个局）。
  - **招牌**：**腰斩**。章盟主的腰斩范围最大、伤害最狠——他的「腰斩范围」是别人的2倍，根震裂概率是50%（普通道君是20%）。散修听到他名字就捂胸口。
  - **与凯哥的关系**：凯哥当年是缠论祖师中最接近晋升的一位，和章盟主对赌过一局猜心——凯哥输了，但章盟主没拿他的道，反而和他喝了一晚上酒。凯哥死前最后一句话里提过章盟主的名字（苏晓听到了，但当时没在意）。
  - **预计出场**：第二章。小屁逃出龙门大厦后，第一个接触到的「真正强者」。章盟主会拿凯哥的信息做筹码，跟小屁做一笔交易。
- **对应现实**：章盟主=知名游资章建平（化名梗）。其余御线道君=控K线形态的操盘手、一线游资。

### 🟡 中层执行阵营（Tier 3-6）

#### 6. 量枢真君（Tier 6·控量）

- **本质**：控「量」的开关。要天量放天量，要地量缩地量。庄家做局的核心技术工种。
- **技能**：仙人指路、量锁。
- **天敌配对**：量枢真君是缠论祖师的天敌——祖师画线觉得要涨，量枢真君一个量锁，祖师当场懵。
- **对应现实**：公募基金经理、控盘资金总监。

#### 7. 对倒仙人（Tier 4·做量游资）

- **本质**：自己跟自己玩游戏，做假量假波动，骗缠论祖师和散修入套。
- **技能**：对倒、量骗。
- **收入**：赚信息差——每次骗100个散修，每人10穗=1000穗=100道，私局分成。
- **晋升瓶颈**：最难升的一阶。升量枢真君需要「拿住一个局的量权」——大多数对倒仙人一辈子拿不到，死在这阶。

#### 8. 抬轿人（Tier 3·马仔）

- **本质**：老祖/道君雇佣的苦力。专门拉红阶、做假突破、骗散修追。
- **技能**：假突破（初级）。
- **收入**：月薪2道 + 局成红包5-10道。
- **命运**：围猎失败第一个被扔出去当弃子（断根替罪羊）。所以抬轿人之间的关系极差——没人愿意和同事一起参加局，怕被卖。

#### 9. 镰傀（Tier 5·量化傀儡）

- **本质**：算天宗炼化的器。没有感情，没有休息，7x24小时割。
- **技能**：群体腰斩（弱化版，只扣穗），每15分钟自动发动一次。
- **分布**：龙门大厦1-30层每层游荡2-3个。不进禁区，不攻击天台守护者（豁免条款）。
- **维护**：算天宗每日发「维护穗」。坏了直接拆了当废料，再炼新的。
- **对应现实**：量化高频交易程序、自动交易机器人。

### 🟢 散户阵营（Tier 1-2）

#### 10. 缠论祖师（Tier 2·技术天花板）

- **本质**：散修天花板。熟读千种形态，画线精准，头头是道。靠技术赢道，是散修中的「传奇人物」。
- **能力**：无技能发动权，但能「看破」技能效果前兆——比如假突破前3息祖师能感觉出来，可以躲避。
- **致命弱点**：**顶底背离**。算天宗的专属技能，专门骗技术派——祖师画线画出来的「顶/底」，全是算天宗故意画给他们看的。他们读的每一本「缠论秘籍」，都是御线道君编的。
- **凯哥（主角发小·已逝）**：生前就是缠论祖师中的佼佼者，距离晋升抬轿人只差一步——但被天尊合同陷阱坑了，道尽后跳红阶自断其根。
- **对应现实**：民间股神、技术分析大佬、大V老师们。

#### 11. 散修（Tier 1·韭菜）

- **本质**：青原90%人口。靠穗生存。
- **心态**：每个人都觉得自己与众不同，觉得下一把就能赢，觉得自己不会是那最后一个断根的。
- **死亡路径标准模板**：
  1. 穗赚了几把（赢零花钱开心）
  2. 赌大的，道赢了（存款翻倍膨胀）
  3. 被仙人指路/假突破骗，道输一半
  4. 不甘心，去笑面虎那里借根押根（加杠杆）
  5. 被腰斩，道穗全没
  6. 借根到期还不上
  7. 根断 → 枯壳 → 草海喂狼/做刀条
- **对应现实**：90%的A股散户。

### 🔵 借根铺势力

#### 12. 笑面虎（借根铺老板·青原最大）

- **等级**：**表面 Tier 4（对倒仙人级），实际 Tier 7（私下有御线道君实力）**——他隐藏了实力。没人知道他真实水平。
- **生意**：借根局全青原市占率70%。其他小借根铺都是他的下线。
- **性格**：永远笑眯眯，签合同手最快。不管你欠多少，他都笑着和你说话——直到按根纹抽根的那天，他还是笑着的。
- **与庄家关系**：表面附庸，实际合作。天尊是借根铺最大股东，笑面虎拿30%分成。
- **与凯哥关系**：凯哥当年的借根合同就是笑面虎签的。凯哥的「天尊认定条款」是笑面虎亲手用极小字体写上去的——他知道凯哥必死。但笑面虎也偷偷留了一手：凯哥的合同他没交给天尊，藏在自己保险柜里。**后期伏笔**：这份合同里有凯哥根纹的完整拓印——比根牌上那片屑完整得多。
- **倒戈可能性**：纯粹商人。谁给的多帮谁。第二章会和小屁做交易——用凯哥的合同原件，换一样东西（什么东西？待定）。
- **对应现实**：最大配资公司老板、地下钱庄老板。

### ⚪ 守护者阵营

#### 13. 苏晓（天台老板娘/守护者领袖）

- **等级**：**主动放弃晋升。** 她实际水平能到量枢真君（她哥凯哥教她的），但她立誓不碰游戏不升级——等级永远停在「缠论祖师候补」。
- **豁免**：天台范围内借根铺不追债，围猎/技能不碰顾客。
- **代价**：每月交保护道（逐月递增）；庄家可在天台随时举办公开处刑（含断魂刀），她只能旁观。
- **致命开关**：天台任一成员破戒（参与游戏/发动技能/放贷）→豁免自动失效→全员成为围猎目标。

#### 14. 天台众人（守护者团队）

每个人都有等级，但都「自废修为」留在天台帮苏晓。

| 人 | 原等级 | 惨事 | 现在职责 |
|---|---|---|---|
| 老炮 | 前御盘老祖级（围猎团头狼·Tier 8） | 围猎失败被反围猎，全家根断只剩他；苏晓用自己根的三分之一救他回来 | 天台总管，培训新员工 |
| 红姐 | 前缠论祖师级（Tier 2） | 嫁御盘老祖→老祖被围猎根断→她被抵债青楼三年→苏晓用一年保护道赎出 | 天台荷官 |
| 瘸子 | 前量枢真君级（Tier 6·龙门大厦保安队长） | 阻止凯哥处刑→被白衣人下令打断双腿→扔出楼→苏晓救下 | 天台门岗/看死局/信息贩子头子 |
| 哑巴 | 前御线道君级·猜心无敌（Tier 7） | 当众说破庄家「三盏灯温度控制」作弊→被白衣人下令割舌→苏晓救下 | 后厨+看穿一切技能但说不出来（打手语） |

### 🟣 其他势力

#### 15. 信息贩子

- 最靠谱的：瘸子（门口听来的一切，只卖给有缘人）。
- 最不靠谱的：龙门大厦外围散布谣言的散修——90%消息是天尊放出来的饵（东边有出口/今晚章盟主不在/某某老祖要发动仙人指路）。

#### 16. 散修自救互助会

- 老散修凑道互保，凑得越多，收网时天尊越肥。通常存在不超过3个月。

#### 17. 「反天尊」地下组织（后期登场）

- 传说中存在。目标：掀翻龙门大厦，杀天尊。
- **内部有没有天尊内鬼？** 有——而且是高层。青原什么都能博弈，包括「反抗」这件事本身。

## 三、天尊矛盾转移机制（统治核心）

> 让散修恨散修，让缠论祖师恨抬轿人，让老祖恨章盟主——
> 没人恨天尊。因为没人能看到天尊。

| 手段 | 效果 |
|---|---|
| 围猎制度 | 散修→恨围猎团，不恨天尊 |
| 等级晋升制度 | 散修→想当抬轿人/老祖，目标是「吃得住别人」而不是「反天尊」 |
| 章盟主中立设定 | 老祖→恨章盟主（被他腰斩过），散修→怕章盟主（他的腰斩），没人恨天尊 |
| 白色指数 | 散修→以为指数是天尊盈亏，恨的是「运气不好」「别人太贪」 |
| 公开处刑+断魂刀 | 观众→下注赌别人撑几轮，别人的痛苦是我的娱乐 |
| 家人连坐条款 | 散修→优先保家人，不敢反抗，即使知道真相也不敢说 |
| 天尊从来不出面 | 散修→只见过白衣人和老祖，恨的对象永远是具象的人，不是抽象的天尊系统 |

天尊最厉害的从来不是断魂刀——而是**你恨的永远是旁边那个人，而不是设计了刀的人。**
