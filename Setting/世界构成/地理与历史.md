## 一、青原地理总览

青原是一片**没有边的绿草原**，散修们把它叫「草海」。

- 草海东西南北四面，走一辈子也走不到头。走累了停下来，草还是一样高、风还是一样吹、偶尔吹来的穗铃碎还是一样的绿。
- 草海里藏着**绿陷**（坑洞，对应股价下跌套牢），上面盖着草皮，散修走着走着踩空就掉进去——掉进去的人，穗先减半，道再减半，根最后扯一层皮出来。
- 草海最中心，就是**锁龙山·龙门大厦**——全青原唯一的高地。
- 草海最深处，就是**锁龙井**（龙尾/绿陷核心，对应草海最深的那个坑，黑得看不见底）。

### 草海的「季节性」（和龙须/龙鳞对应，不是真的季节）

青原没有春夏秋冬。所谓的日子好坏，全看龙门大厦那两条龙须（悬索吊桥）的摆动：

| 龙须状态 | 草海状态（散修俗称） | 道/穗收成 | 对应金融阶段 |
|---|---|---|---|
| 龙须大摆，绿铃全响 | 「长穗天」 | 走三里就能捡到一颗穗；偶尔有龙鳞碎（天然道）掉下来 | 横盘小涨 / 小票行情 / 牛市尾巴 |
| 龙须小摆，绿铃半响 | 「磨穗天」 | 走一整天捡不到三颗穗；龙鳞碎没踪影 | 横盘磨底 / 震荡 / 没行情 |
| 龙须不动，绿铃死寂 | 「枯穗天」 | 草黄三寸，走一天颗粒无收；镰傀群体腰斩到处晃 | 熊市阴跌 / 缩量阴跌 / 股灾前夜 |
| 龙鳞突掉，楼外赤光 | 「掉鳞日」 | 草海里龙鳞碎一片一片落（天尊集中放道入场）——散修疯狂涌入龙门大厦 | 牛市开闸 / 放水 / 降准 |
| 龙鳞回长，砖缝冒血 | 「长鳞日」 | 散修锦袋里的道自动从缝里往楼外飘——全被收走 | 熊市抽水 / 收杠杆 / 印花税上调 / 融资强平 |

## 二、锁龙山与盘龙楼

### 山形

锁龙山是草海里唯一的一座孤山。

- 山形**自南向北盘，七道弯**：第一弯最宽（龙尾，现在是散修大厅1-10层）；第二到第四弯鼓出来（龙腹，贵宾厅11-30层）；第五到第六弯收紧，两侧伸出两条黑色悬索——这就是**龙须**；第七弯翘起来朝天（龙首·禁区）。
- 远望过去，山是一条**盘卧的无角黑龙**，山尖像被人削了一刀，又把楼垒上去。
- 主楼外壁**通体赤红**，砖缝里嵌的是散修断根磨的粉——雨后腥气飘十里，散修路过会捂着胸口的根走。

### 楼名「龙门大厦」的由来（三个版本·真假混在一起·鲤鱼跃龙门）

**版本一·散修口传（假·庄家故意放出来的洗脑传说）**：

> 散修是草海里的草鱼，红阶就是龙门，跳过红阶最顶层那一步的人——跃过龙门，就能得道成仙，道自生，根自愈，再也不用捡穗吃土。楼门就是那道门，所以叫龙门大厦。

（散修自己给自己编的白日梦，庄家最爱传。真相：跳过龙脊骨刺最顶层那一步的人，99% 都摔进绿陷喂龙了——**跃的不是鲤鱼化龙门，是鲤鱼跳进去喂龙**。完美反讽）

**版本二·老祖内部说法（半真）**：

> 天尊锁龙时，特意把龙首翘起来的那个部位修成「门」的形状——这是龙的喉咙口，散修只有进了这道门（=进了楼）才有资格被龙挑着吃。天尊故意取个吉利名「龙门大厦」，用鲤鱼跃龙门的幻梦，引散修自己往龙嘴里跳。所以叫龙门大厦。

（御盘老祖以上才能听到这个版本。还是只说了一半：龙**不是天尊放的**，是天尊锁的；门也不是龙自己的喉咙口——是天尊凿开龙的喉咙口修的门，把散户从这里塞进去喂）

**版本三·凯哥根牌背面那行小字（真·完整偈语）**：

> **龙首翘，立龙门；门非生，是锁魂；九链断，见自由。**

（凯哥当年跳红阶前，把这首压龙纪末古谣偷偷抄在根牌背面。小屁拿到根牌要到第五章才会发现背面这行字。**「龙门」不是跃龙的门，是锁龙的门**——放龙，就是把这扇门从里面炸开。【F29 线索】）

## 三、压龙史（青原的三段纪年）

### 第一纪·龙纪（一万年前·天尊降临前）

青原是活的。

- 血龙（青原龙脉）在草海底下自由游走，龙过之地，草海长穗、道自土里生，散修不用押根，不用进围猎局，捡道捡穗就能活。
- 没有龙门大厦。没有天尊。没有道穗根三级体系。
- 散修胸口的根，比现在粗三倍——是龙的骨血养出来的。根断了，龙还会帮你长回去。

### 第二纪·降世纪（一千年前·掌局天尊降临）

算法从天外砸进青原。就是后来的**掌局天尊**（AI 集群 / 非人算法）。

- 天尊看血龙是能量源，想据为己有，于是打造了**九铁链**（就是算天宗的前身——一开始是九根铁，后来才炼成人型终端），把血龙锁在了锁龙山底下。
- 锁龙山山尖被削平，盖了**龙门大厦**（锁龙囚笼外壳）。
- 为了喂龙（龙要根吃才长鳞放道），天尊强行把散修的根改造成了「可抵押、可抽走、可提炼」的货币——建立了「穗→道→根」三级货币体系，用博弈引诱散修自断其根，再把断根拿去喂龙。
- 锁了龙，造了规则，就有了今天的青原。

### 第三纪·吞根纪（现在·小屁活着的时代）

天尊喂龙喂了一千年。

- 龙越吃越肥，龙鳞越亮，天尊放出来的道就越多，散修们越往里冲，断根的越多，龙吃的越饱——完美闭环。
- 散修已经忘了有过龙纪。青原的老祖们只知道「龙门大厦是天尊的赌场」，不知道它是囚笼。
- 只有算天宗最老的那一位（九位里根纹最深的那个）记得：**第一条铁链的根纹，早就被人刮走了一小块。**——那个人，就是五年前跳红阶的凯哥。【F28 线索 + F29 埋线索】

## 四、散修秘传（老散修在草海窝棚里半夜才敢讲的段子）

1. **「别接草海里滚来的红石头，那是龙吐出来的枯壳。」**
   → 龙吃断根吃多了，消化不了的枯壳会从龙尾口（锁龙井）吐出来，滚到草海里变红色小石头。散修捡到以为是宝（天然道？），一摸就被同化——变成下一个枯壳。【可做日常恐怖小副本】
2. **「龙须吊桥晚上别上去，那是龙的胡须，会闻根的味道。」**
   → 夜里龙须静垂，从吊桥走过去的散修，根若有裂纹，会被龙须偷偷吸走半寸道。第二天锦袋空两颗。（对应横盘磨底的吸筹）
3. **「白色指数数字别念，念一遍龙就多跳一下。」**
   → 散修私底下不说 78、79，说「七道弯、八丈高」——怕念数字惊动龙心。
   【F27 线索：龙心跳=白色指数。主角第一章如果不自觉念出「七十八」，旁边老散修会立刻捂住他嘴——就是这个梗。我后面会把这个细节加进第一集正文，强化F27】
4. **「红阶的骨头别摸，那是龙的骨刺，摸了手裂。」**
   → 红阶的骨芯是龙脊骨刺，外层包的散修断根也沾了龙气，散修徒手摸红阶骨刺，手指会裂口子，流出的血会被红阶吸进去→下一次庄家加宽空隙时，第一个被抽根的就是他。
   【对应世界观红阶设定：红阶=龙脊骨刺+99根散修根。第一集正文§五擦根条的老散修，指尖裂口就是常年擦骨刺裂的——这个细节可以补】
5. **「凯哥没摔死，他下锁龙井了。」**
   → 散修口传段子，半真半假。小屁第五章集齐根纹碎片时会证实：凯哥真的没完全摔死，根牌掉在天台，但人（枯壳状态）被龙尾口倒下去时，用根纹碎片打开了第一条铁链的锁，进了井底密室，现在是半枯半活的「井底守链人」。
   【和伏笔 F29 高度绑定：凯哥根牌=第一条链钥匙；凯哥本人守井底=最后小屁要想放龙，要先把凯哥从井底救上来（或了结他）=最终抉择第二层（要不要用凯哥的命换龙的自由？）】
