# 时间线

> 第一章·观音村篇 事件先后与角色行动时序
> 月圆夜为锚点倒推

---

## 时间锚点

- **月圆夜**（集9-10）：火刑日，算力峰值，全书高潮
- 双主角入村日为月圆前第7天

## 事件时序

### Day -7（集1）·入村
| 时段 | 事件 |
|---|---|
| 晨 | 双主角入村，雾浓路阻；村长接待，警长冷眼 |
| 午 | 查挖坟案现场：尸骨跪姿面神像，七窍塞黑纸；鱼人察觉旧机关痕迹 |
| 午后 | 见神像满墙锦旗；鱼人旁白点破"都是求子的"；偶见小女孩头顶黑物 |

| 夜 | 祭司宣布神像七窍渗血，全村跪拜；鱼人见神像底座微光一闪 |

| 时段 | 事件 |
|---|---|
| 子时（集8） | 双主角赴约，米老头从神像后密道现身；揭身份+寻物偶遇；摊牌救人计划 |

| 夜 | 大祭司败露跌落神坛，村民反手用51%共识判他"有罪"触发自燃；神像裂开露算力节点 |

| 时段 | 事件 |
