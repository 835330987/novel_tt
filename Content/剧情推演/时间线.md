# 时间线

## 时间锚点

- **Day 0**：主角输光一切，登龙门大厦寻死
- **Day 1-3**：入职天台，背菜单
- **Day 4+**：开市日，破戒帮人，连锁反应

---

## 事件时序

### Day 0（集1）·登楼
| 时段 | 事件 |
|---|---|
| 白日 | 主角自述惨败（道穗根全光），站在龙门大厦楼下 |
| 午后 | 排队押红印、见白屏七十八、老头捂嘴 |
| 傍晚 | 坐电梯直达顶层，电梯里全是体面赴死之人 |
| 夜 | 走红阶上天台，见「天台来帮您」招牌，被老炮拦下 |

### Day 1（集2-3）·看透
| 时段 | 事件 |
|---|---|
| 夜 | 老炮带路扒光最后道穗；旁观公开处刑（一字断魂刀5轮） |
| 深夜 | 冲向天台边缘被苏晓拽回；苏晓问小白狗；给名片 |

### Day 2-3（集4）·入职
| 时段 | 事件 |
|---|---|
| 白日 | 小屁晃三天，没脸回家，决定去天台面试 |
| 午后 | 面试崩溃大哭被叫「小屁」；入职三条规矩；拿菜单 |

### Day 4（集5-6）·培训
| 时段 | 事件 |
|---|---|
| 白日 | 背菜单（表面菜名vs暗语K线）；第一次旁观围猎四步曲 |
| 傍晚 | 笑面虎在人群里挥手认出小屁（债主） |
| 次日清晨 | 开市仪式（敲钟+红阶点燃）；白色指数跳动；镰傀出现 |
| 白日 | 白衣人上门收保护道（涨价）；老炮点破白袍胸口空 |

### Day 5（集7）·破戒
| 时段 | 事件 |
|---|---|
| 开市 | 年轻散修求小屁救母；小屁破戒教猜心 |
| 午后 | 年轻散修赢了磕头感谢；红姐看见叹气 |
| 夜 | 老炮警告「庄家可能已经知道了」 |

### Day 6（集8-9）·代价
| 时段 | 事件 |
|---|---|
| 白日 | 白色指数疯牛（破90）；红阶存穗暴增；散户疯狂跳台 |
| 午后 | 年轻散户膨胀跳红阶→庄家加宽空隙→摔死绿陷→白色指数涨一格 |
| 夜 | 小屁崩溃独走草海；目睹绿陷连环（5人串吞） |
| 深夜 | 瘸子背小屁回来；苏晓讲凯哥完整真相 |

### Day 7（集10）·审判与逃亡
| 时段 | 事件 |
|---|---|
| 夜盘 | 白衣人上门拿人（破戒借口）；小屁上台处刑 |
| 处刑中 | 两轮输→第三轮同色（苏晓破戒改程序） |
| 处刑后 | 苏晓公开揭露凯哥死真相；观众炸锅 |
| 混乱 | 老炮瘸子抢人；红姐关灯；密道逃亡 |
| 逃亡中 | 苏晓塞凯哥遗物根牌；远处章盟主发动腰斩 |
| 章末 | 章盟主看到根牌收手，朝小屁微微点头 |
