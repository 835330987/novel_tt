# 游戏设计·踩泡沫

> **一句话**：把啤酒倒进看不见的杯子里，猜酒到底有几分——**猜得准是你的本事，忍得住才是你的钱。**
> **主题**：市场＝实体（酒）＋泡沫（泡）。杯壁上的泡痕是它冲上去过的位置；泡沫消散的时间，是全楼唯一诚实的钟。
> **落点**：[[主线剧情_草稿]]插集库·插七「玻璃杯」／插八「黑陶杯」（插在集11与集12之间），楼下版留作第二章接口。
> **相关**：[[支线剧情]]·支线N｜[[伏笔管理]]·F63/F64/F65｜[[创意管理]]·4.4｜[[人物MOC]]·围龙三佬

## 〇、定位：为什么天台需要这个局

| 已有局 | 考什么 | 踩泡沫考什么 |
|---|---|---|
| 三扇门（插三） | 概率盲区——信息没变，是你不会看 | — |
| 天台游戏（集10） | 贪婪与下桌纪律 | — |
| **踩泡沫** | **信息不对称＋时间**——信息本身是被污染的，且真值要等时间兑付 | 全部 |

三扇门考「换不换」，踩泡沫考「**信不信、等不等、踩不踩**」。它是天台第一个把「假消息」「信息战」「时间价值」做成明规则的局，也是全稿「泡沫与实体」这一课的具象化道具。

**天台无钟**（世界观既有设定），全楼的钟都停在两点四十五。只有踩泡沫桌的钟是活的——**泡，就是钟。** 泡沫升起来是开市，泡沫死透是出清。这桌是整栋龙门唯一「时间还在走」的地方，与复盘室（F36/F57 停摆的钟）形成全书级对仗。

## 一、器具与场地

| 器具 | 说明 | 隐喻 |
|---|---|---|
| **玻璃杯** | 教学桌专用，透明 | 教科书市场／监管全透明的理想市场 |
| **黑陶杯** | 正式桌专用，不透光 | 真实市场：你永远看不见里面的比例 |
| **沉淀盅** | 开盅后倒酒入盅静置，泡死见酒线 | 价值回归／出清 |
| **钟杯** | 每轮另倒一杯当计时，泡死＝截标 | 市场出清时间／周期 |
| **泡缸** | 刮下的泡沫、溅出的酒，全归缸 | 交易摩擦成本／庄家抽水 |
| **踩牌** | 每队一枚，亮牌即开盅 | 主动平仓／止盈时机 |
| 扁担（围龙队自带） | 脚夫身份物，靠柱不落地 | 底层自带的「本钱」 |

场地：天台离围栏最远的角落（组长规矩：热闹的局离围栏远）。招牌一块——**「踩泡见酒」**。

**天台无钟 → 泡就是钟：** 泡升起来是开市，泡死透是收盘。温酒的钟杯死得快＝短庄节奏；冰酒的钟杯死得慢＝长牛假象。**倒酒的人连时间都能做给你。**

## 二、基础局规则（个人局）

### 2.1 流程

1. **倒酒**：教学桌店家倒，正式桌对家倒（见第三节）。
2. **报数**：客人写下「酒几成」（一成到十成，握拳＝报空杯）。
3. **押注**：入池。
4. **开盅**：倒入沉淀盅，静置，泡死见酒线。
5. **结算**：误差最小者独得池；误差最大者喝「全泡」——一杯子泡沫，喝一肚子气。

### 2.2 报空（做空）

敢报「空杯」（杯里没酒、全是泡）者，猜中独吞双池；猜错罚喝全场所有杯的泡。**赢大赔重——做空的报酬与风险，一起具象化。**

### 2.3 踩牌：快踩／慢封／逼踩（核心张力）

- **快踩**：亮踩牌，立刻顿杯开盅，泡死见真值——但顿杯必溅，**洒出去一成酒**，归泡缸。
- **慢封**：不出牌，盖纸等到钟杯泡死统一开盅——不溅，但要等，而且中途对家可以「加注逼踩」：加注你不跟，按弃权小额认输。
- **庄家稳赚的秘密**：每次快踩／开盅，刮泡入缸。**天台不怕你赢，怕你不踩。** 倒酒的手、免费的酒、催单的嘴、吵闹的唱机，全是逼你踩的东西。

> 这就是「时间的朋友 vs 快速出击」的规则化：快＝信息在手但要交磨损；慢＝真值完整但考验性子。**踩泡的人急，急了就洒；洒出去的酒，不归你也不归他——归缸。**

### 2.4 教学桌的机关（养肥再杀）

第一杯永远用玻璃杯，让你赢、让你信手；第三晚起全换黑陶杯。**玻璃杯里的八成是八成，黑杯里的八成，是你信不信的八成。**（对应「玩游戏用的是玻璃杯，真正的市场用的是不透明的杯子」。）

## 三、进阶局：互相倒酒（信息战）

### 3.1 倒酒手法表（庄家手法对照）

| 手法 | 做什么 | 市场隐喻 |
|---|---|---|
| **高冲** | 举壶高倒，泡沫轰起 | 拉高对倒、放量造势——泡最高的时候酒未必最多 |
| **贴壁低斟** | 沿杯壁慢慢溜 | 低调建仓／吸筹，不起泡 |
| **断续斟** | 一顿一顿地倒 | 脉冲放量／对敲 |
| **晃杯** | 先晃后倒，旧泡带新泡 | 换手／接盘 |
| **温酒** | 温过的酒泡死得快 | 短庄快进快出 |
| **冰酒** | 冰过的酒挂杯不散 | 长牛假象、画出来的慢牛 |
| **油指头** | 小指抹杯沿，泡应声而灭 | 黑手砸盘／内鬼做空（作弊） |
| **假洒** | 喊「洒了半壶」，实际收进袖里 | 出货时喊利空 |
| **洗杯** | 趁乱换杯换位 | 洗盘／调仓 |
| **换泡** | 旧酒新摇，死酒装活泡 | 假突破／僵尸股画线 |

### 3.2 话术规则

倒酒时嘴上随便说——**话不算数，酒才算数。** 说出口的一切＝消息面，允许全盘撒谎。这就是「假消息」的规则化：**嘴上可以有泡。**

### 3.3 声音是证据

泡沫声是「沙沙」，纯酒砸底是「咚咚」；刚摇过的杯会嘶嘶吐气，死酒一声不出。**听声辨酒＝量不会说谎**（与F46「资金流向不说谎」同源，也是盲人手的立身之本）。

## 四、团队赛制：聋·瞎·哑三人局（核心）

### 4.1 角色与封印

| 角色 | 封印 | 道具（剧情内依据） | 能力 |
|---|---|---|---|
| **眼**（能看的人） | 能看，**不能操作，不许出声** | 双手捧白毛巾盘，手不离盘 | 看对家倒酒、话术、一切小动作；只能打手势 |
| **嘴**（传话的人） | 有嘴，**听不见** | 双耳封蜡（黄酒封坛的红蜡） | 只看手势，翻译成话大声说给手听 |
| **手**（能操作的人） | 能操作，**看不见** | 蒙眼黑布（擦杯布） | 听声辨位，按口令选杯、移杯、报数、决定快踩或慢封 |

规则：三人一桌，**谁也不许替谁**。眼的手碰杯＝犯规；嘴听声反应＝犯规；手掀蒙布＝犯规。

「眼不许出声」的剧情依据：天台老规矩——**看盘的不许喊单**，喊单的按荐股罚。「嘴听不见」的剧情依据：封坛蜡封耳，**不听消息的人才配传话**——他传的不是消息，是盘面。

### 4.2 单轮流程

1. 对家给我方倒三只黑杯（互相倒酒），全程带话术；我方同理倒给对家。
2. 对家另倒一只「钟杯」，泡死＝截标。
3. 眼看 → 手势 → 嘴翻译出声 → 手执行。
4. 截标前决定：快踩 or 慢封。
5. 开盅：沉淀盅静置，泡死见酒线，误差小者胜。

### 4.3 手势语法（示例）

| 手势 | 含义 |
|---|---|
| 伸指N | 酒N成 |
| 握拳 | 空杯（建议报空） |
| 手指转圈 | 泡厚，虚高 |
| 指腕下垂 | 泡将死，快开盅 |
| 捏鼻 | 对家在说假话 |
| 拇指食指一搓 | 油指头，有人作弊 |
| 掌心下压 | 慢封，忍住 |
| 拳砸桌沿 | 快踩，就是现在 |
| 弹指 | 对家话术，一个字别信 |

开场前可商定全队自定义暗号——但商定过程全楼听得见。**除非你有「暗语」（见五：方言密码）。**

### 4.4 攻防三板斧

**攻方**：①喂假象（假倒、假洒、假手抖）②拆手势（派人在场学你家手势，三轮之后你家手势等于明文）③拆耳朵（唱机噪音压制蒙眼的手）④洗杯换泡（趁乱调包、旧酒新摇）。

**守方**：①看痕不信嘴（杯壁挂泡痕＝历史高点，杯底水圈＝动过的证据）②听声不信眼（嘶嘶＝活气＝刚摇过；闷响＝死酒）③菜单密码（拿店里雷霆菜单当密本，主场优势）④反话与沉默（关键轮让嘴闭嘴，让对家学无可学）。

### 4.5 为什么这三个人合起来才是市场本身

散户三死穴，一桌治一个：

- **眼＝治「看见就想动」**：散户盯着盘手就痒。让他看穿全场，偏不许他碰一根杯毛。
- **耳＝治「听见就信」**：散户十次上头九次因为耳朵。封了耳，只剩盘面。
- **嘴＝治「亏了不认、赢了喊单」**：说出口的话全楼听得见——等于把仓位挂在大街上。

> 台词（老板娘或贱人）：**「你们一个个下来玩，都是残疾人。这三个人凑一桌，才是一个完整的交易员。」**

### 4.6 变体

- **二人残局**：看兼说（聋）＋做（瞎）——更吵更乱，天台管这叫「残局」。
- **哑巴局**（高级表演赛）：两队的嘴都封耳——全场只剩手势和泡声，观战比下场刺激。
- **楼下版**（第二章接口）：大排档散装啤＋粗瓷碗。碗挂不住泡——**楼上的杯子黑，楼下的碗反而亮堂**。围龙队的主场，注码用钱不用穗。

## 五、围龙队：客家三人组（信息战的具象化）

### 5.1 人物档案

| 人物 | 角色 | 一句话 | 细节 |
|---|---|---|---|
| **石鼓** | 眼 | 话极少，一双眼把人刮三遍 | 围屋看楼佬出身；能凭口音认人——**口音就是籍贯，籍贯就是根纹** |
| **广播** | 嘴 | 嗓门大，普通话「差」，差得很准 | 双声道操作者：明语频道放假消息，方言频道传真指令 |
| **铁桶** | 手 | 蒙眼端酒纹丝不洒 | 脚夫，挑担练的手；听声辨酒；围屋规矩「手上不能脏」——作弊自己报 |

群像细节：三人一壶酒、三只杯轮着斟，谁也不许多喝一口；扁担靠柱不落地；铁桶坐下先倒扣自己的杯——**倒扣杯，在围屋是「手上干净」，在天台是「劝人下桌」——同一个手势，两套语言（手势也有方言）。**

来历：围屋脚夫班，假期来龙门投标「脚钱」（货梯承包权）。

### 5.2 优势机制：双声道

普通话队的一切口头信息都是明文，围龙队随便听；围龙队的客家话对外是完全加密的。于是他们可以：明牌开会、当面用「差劲的普通话」放假消息、真正的战术全在方言频道里说完。**明文发假电报，密文传真指令。**

### 5.3 劣势与裂缝（智斗的抓手）

1. **手势没有方言**：手势是通用语，三轮就会被学走。
2. **痕迹没有方言**：泡痕、水圈、嘶嘶声不认语言。
3. **习惯有方言**：石鼓的tell、广播的节奏，盯久了就是明牌——**别听他们说什么，看他们手上做什么**（凯哥课的前置呼应）。
4. **抱团即裂缝**：围屋规矩「手上不能脏」——铁桶当场自报油指头，广播与铁桶内讧，**方言密不透风，家法先漏了风**。

### 5.4 底账（可选，待拍板）

族里公账被借根铺吃掉，来龙门学局、赢本钱。接[[支线剧情]]笑面虎线／货梯线；货梯班入职后可与插五「腌萝卜罐六道刻痕」（F56）挂接口（默认留白）。

## 六、小屁的语言根纹（F63·全稿级反转）

### 6.1 语言清单与来历

| 语言 | 来历 |
|---|---|
| 普通话 | 门面 |
| **白话（粤语）** | 电视学的——员工区电视墙天天放白话剧 |
| **客家话** | 妈妈那边——围屋迁出来的母系 |
| **闽南语** | 爸爸那一辈——讨海下南边的父系 |
| 英语 | 站台广播＋课本 |

背景：他老家是**交通枢纽城市**——「三条铁路在城里打结」，编组站的站台广播一天换四种腔；亲戚各奔东西，过年一张桌坐五种腔，菜要转着圈敬，话要换着频道讲。**「枢纽城市长大的小孩，耳朵里天生住着一个码头。」**

### 6.2 「就是这么逆天」的包装策略

- **不让叙述者辩解，让角色替读者骂**：贱人——「你系咪人来的？」
- **用世界规则给巧合上保险**：石鼓凭口音验证——「你个腔，是江口调。」口音有地址，地址对得上靓妈的围屋。**巧合从此变成可以查证的档案。**
- **三闲笔前置**（插七埋）：员工区白话剧／闽南客点单／洋行番客问路——当时没有一个人在意。

### 6.3 三段式

| 段 | 位置 | 内容 |
|---|---|---|
| 埋 | 插七 | 三个闲笔＋围龙队入场（没人注意小屁在场边听了全场） |
| 露 | 插八中段 | 小屁的「失手」总恰好躲开话术陷阱；围龙队起疑改纯手势；石鼓开始盯他 |
| 爆 | 插八终局 | 客家话点破换杯→白话回敬贱人→闽南语应客→英语待番客→口音验证收束 |

### 6.4 情感押韵（本设计的题眼）

- 靓妈打电话，只有一句用围屋话讲——「返来食饭」。**围龙队用方言锁生意，他阿妈用方言锁团圆。同一把锁，两扇门。**
- 贱人的白话腔（呐／咯／喔）小屁句句听懂——「全楼最会听的人」身边站着一个「全楼最会装听不懂的人」。
- 代价：老板娘的目光（他不再是家具）→ F65 玻璃杯下架；围龙队记住了他 → 第二章物流线接口。

## 七、事件链（插七／插八分幕）

### 插七·玻璃杯

1. 新局开张，教学桌玻璃杯人人赢，免费酒——**白给的都是钩子前半截**。
2. 泡痕首秀：泡塌了，杯壁挂痕，「酒没了，痕还在」。（F64埋）
3. 转黑陶杯，赢红眼的客人当场破防——玻璃八成是八成，黑杯八成是信不信。
4. 胖姨刮泡入缸，「溅出去的酒归缸」——庄家抽水首秀。
5. 围龙队入场：一壶酒三只杯一根扁担；铁桶倒扣杯（两套语言）；广播下战书赌「脚钱」；老板娘拍板三人局。
6. 收尾三闲笔（F63埋）＋钩子。

### 插八·黑陶杯

1. 规则宣读：聋瞎哑封印；店家队＝小屁（眼）＋贱人（嘴）＋瘸腿大哥（手）。
   - 分工的戏：贱人被封耳＝全楼最会听的嘴闭上了；小屁被按在「看」的位置＝赌徒戒手瘾；瘸腿大哥自荐——「这双手端了二十年盘子」。
2. **第一轮「高冲」**：店家胜。小屁看穿喊得最响的杯泡厚酒不多。
3. **第二轮「洗杯」**：店家败。满桌水圈，真痕假痕一个颜色——**第一次见识「做出来的痕迹」**。
4. **第三轮「油指头」**：铁桶蒙眼听声自报作弊，围屋家法先漏风；「瞎子听见了眼睛没看见的」。
5. **第四轮「唱机」**：噪音压制蒙眼的手；贱人吹口哨传信——**聋子吹哨，自己听不见自己吹的是什么，错一个音满盘皆输**。险胜。
6. **中场「告示局」**：店家贴告示「今晚新酒开缸」，广播见利好当场加注逼踩；小屁验出是昨晚泡缸回收的底子兑的——**利好是真的，酒是昨晚的**。两家都没动，泡缸白捡一池泡。
7. **第五轮「全押」**：围龙把脚钱合同押上桌。广播用客家话大声「安排战术」——小屁听懂了，却发现这套话四刻钟前就讲过、一个字不差：**话是旧的，活早就干完了，能信的只剩桌上的痕**。铁桶借搬唱机预倒换杯、死酒新摇。开盅前小屁以店家「验杯权」开口——**客家话**：「死酒装活泡——杯底的痕，比你们的话新。」
8. **揭示瀑布**：石鼓问「你阿姆系哪围人」→口音验证（江口调）→「讲得出口，就是半个自家人，输了局不输人」→贱人白话「你听懂我平时讲你咩」→闽南语应客→英语待番客→枢纽城身世自述。
9. **结局**：店家胜局，老板娘仍把货梯包给围龙——「这栋楼缺的不是会赢的手，是不换杯的手」。打烊后独盅静置，天亮酒线＝小屁第一晚报的数。**人散了，泡就散了；剩下的，都是酒。**
10. **余韵**：泡缸一夜泡，早上剩一层水（胖姨：「白忙一整夜，就剩一口唾沫」）；老板娘下令撤教学桌——**「玻璃杯太亮」**（F65）；扁担入货梯，萝卜罐六道痕留白（F56接口）。

## 八、道理的落地（谁来讲、怎么讲——不布道）
