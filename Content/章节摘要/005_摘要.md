# 005 第五集 · 速览（暂定名：小屁落地）

**【本集定位】** 004 是全程向内的审判，005 是一脚踩回地面的「落地章」。内心王朝的死刑刚执行完，现实立刻以一套冷漠流程接住他：两位看戏的老客从他的喃喃自语里，反推出这场史无前例的停牌是冲他一人关的；话音未落，他被当成碍路的物件架走，随即以「重点嫌疑人」之名被无限期留置。食宿费掏不出，他只能打杂抵债，从赴死者变成天台的囚徒与替补伙计——清晨一声「小屁」，旧名死去，新我在最高处落地。**身份转换：赴死者 → 天台囚徒 / 替补服务员（小屁）。**

**【发生】（情节节拍）**

**第一部分 · 刑场余波（内心收束）**

1. **死期将至**：那位名为「贪婪和愚蠢」的昏君死期将至，我不甘心——他由我一手扶持上位，登基盛宴上，我曾向散落在身体各处的子民、向我的父母亲口承诺，这位将领必将带领我们走向繁荣。
2. **亲手摘王冠**：王冠是我亲手戴上的，今天也得由我亲手摘下来。
3. **落回红毯**：刀光在脑子里一闪，王国静了；再睁眼，我还跪在红毯上，膝盖跪得没了知觉，嘴里翻来覆去喃喃——绝不再犯，绝不再犯。

**第二部分 · 龙凤胎（双轨对话）**

4. **递来手帕**：一只手把一块叠得方方正正的手帕递到眼前，不是塞过来的，手腕不抖，停在半空等我自己接——一张东方面孔，男人，眉眼温顺，看年纪四五十岁：“拿着吧，都跪了好一会儿了。”手帕是凉的，沾着淡淡的皂角气。
5. **两张矛盾的脸**：另一个是西洋女人，高鼻梁、深眼窝，年纪相仿，说中文每个字却咬得又准又硬，像拿刀子在切。一东一西、一男一女，却是一样的年纪、一样的眼神路数，像一个模子里扣反了倒出来的。
6. **姐姐恶语点毛病**：“你就有这臭毛病——自己都跪地上了，还在替这些废人掉眼泪，你理他们作甚？一个个自己排着队往下走，有人拿刀逼他们？这种人，用得着你可怜？”
7. **争执·外文谶语**：弟弟“他心软，不是坏事”；姐姐笑了一声：“心软的人我见得多了——”忽然吐出一串又快又硬的外文，自己翻回来，“坟地里，埋的，都是心软的。”
8. **弟弟讲史**：他蹲下与我平视：“子在川上曰，逝者如斯夫。围栏那边的人拦不住，水要往下流。可这个人不一样——他是自己走回来的。”
9. **姐姐漏大事**：姐姐拿手指从「太平门」划到大厅深处：“太平门让人点了。这地方开了多少年，台子说关就关。一模一样的局，我在别处见过——头一夜关门，第二夜……”
10. **山雨欲来**：弟弟轻轻接了一句：“山雨欲来风满楼。”
11. **时间咬合之问**：姐姐眼睛没离开我的脸，看了半晌忽然问：“你是什么时候让人从门里捞回来的？……是不是你前脚让人捞回来，后脚牌子就关了？那么多人，服务生单单捞你一个——你信，这是巧合？”
12. **背景拿人**：说话的工夫，两个黑西装押着个人快步过去；红马甲穿行在桌椅间，板子一翻一合，走到谁跟前谁就站起来跟着走，没一个多问。
13. **卷进大事**：弟弟叹口气：“小友，你怕是……卷进大事里了。”

**第三部分 · 架走**

14. **担保人赔笑捞人**：套过我麻袋、又把我从「太平门」拽回来的服务生挤进来，冲龙凤胎弯腰，脸上堆笑：“两位对不住，对不住，挡着二位了——”胳膊往我腋下一穿，半架半提把我从红毯上捞起，脚步不停往大厅边上带。
15. **两句赠言**：我回头，西洋女人遥遥举杯，像敬又像送，嘴里又念了一句外文，调子拖得很慢，像一句老话；东方男人微微点头，末尾四个字——“……自求多福。”

**第四部分 · 留置与工偿**

16. **举报·皆有嫌疑**：我被按在椅子上。红马甲（红姐）夹着登记板过来：“「太平门」让人举报了，所里的人已经到了。今晚在场的，一个都走不脱，配合调查。”
17. **重点嫌疑人·无限期**：“别的客人陪着等信儿，问完话就走；您几位不一样——您几位是重点。什么时候查清，什么时候算完。”
18. **食宿自理·没钱**：“滞留这些天，吃住都在这儿，费用得自己结。”我张着嘴半天没出声——全身上下掏不出一个子儿，“我……我没钱。”
19. **担保人情商**：服务生弯着腰，半求情半商量：“红姐，他是我从门口捞回来的，登记在册跑不了。留他打个杂吧，端盘子、守饮水机，力气活都能干，工钱先抵吃住，人在这儿、账在这儿，两清。”
20. **请示获准·禁足**：红姐拿对讲机压着嗓子说了好一阵，回来把板子一夹：“行吧，先这么着。丑话说前头——事情没查清，顶层的边，你半步都别下。”

**第五部分 · 热豆浆**

21. **甜度都对**：有人端来一杯东西搁在小桌上，热的，豆腥气里带着一点甜——是我平素最常喝的那种豆浆，甜度都对。
22. **全知背调**：“你们怎么知道——”“来这儿的客人，祖上三代，我们都摸得清。”红姐没回头，“你想干什么，我们比你自己，知道得还早。”
23. **头一回觉得烫**：热气一缕一缕往上走，我喝了一口——活了这么些年，头一回觉得，一样东西，是烫的。

**第六部分 · 入笼**

24. **进宿舍**：几个同事七手八脚领我穿过一条又一条熄灯的走廊，满耳的风被一扇扇门关在身后，最后停进一间窄窄的屋子——上下铺，铁架子，有人给我指了张空铺：“先睡，明天准时起，新人培训。”
25. **无眠**：床板硬，被子上有股晒过的皂角气，和那块手帕一个味道；我合不上眼，一闭眼就是那只悬空往下落的脚、屏幕上不紧不慢跳动的猩红、电话里我妈那句翻来覆去的——家里都好，你别惦记。

**第七部分 · 小屁落地**

26. **清晨推醒**：天刚蒙蒙亮，我让人一把推醒，屋子里站满了人，一个个憋着笑上下打量我。
27. **得名小屁**：一只大手拍上我的肩，拍得我一歪——瘸腿的大哥嗓门大得整层楼都听得见：“行了，小屁，别哭了，该上工了！”我愣了两秒才品过味来：昨夜那场哭，整栋楼都听见了。爹妈给的名字自己都快记不清，这栋楼已经替我起好了新的。

**【主题与意象】**

- 全集的动作方向是「落地」：王冠摘下 → 手帕递来 → 按到椅上 → 新名加身，一路向下、一路被人接住；004 在心里杀了一个皇帝，005 在人间领到一个编号。
- 莫言式双轨：龙凤胎表层争的是“他这个人值不值得”，对话缝隙里压着另一件大事（举报、关门、第二夜）；背景里红马甲拿人、黑西装押客同步发生，话到、人到，不另作交代。
- 矛盾体即世道：一张西洋脸一张东方脸，恶语者句句点醒、软语者句句怜悯；他们不解释自己的来历，也看不透全部，只凭老到的经验把“你是特殊的”这句钩子递到主角手里。
- 温度第一次反转：001-004 他的世界是血的凉，本集一杯豆浆烫得他发怔；手帕与被子是同一种皂角气——天台第一次显出“家”的质感，也可能是“家”的伪装。
- 核心反讽：他在内心刚完成“做自己的主人”的加冕，抬头发现现实连去向都不问他；逃了一辈子、拼上最高处，结果被挂在了最高处。

**【核心伏笔 · 待后文回收】**

1. **“这牌子，是冲你关的”**：史无前例的停牌为他一人而来，服务生单单捞他、时间死死咬合 → 全书总悬念：他究竟是什么人、谁在顶层操盘。回收点：幕后操盘者、主角真实身份。
2. **龙凤胎这对矛盾体**：龙凤胎长着两个人种的脸、姐姐“在别处见过一模一样的局”、二人对场上事了如指掌 → 来历长线，后期可回收其真身与立场。
3. **太平门“让人点了”**：举报人/内鬼之谜，调查铺开、重点嫌疑人名单 → 长线悬疑；回收点：举报动机、内鬼真身。
4. **架人时的暧昧**：服务生嘴上赔笑、手上不停，像清理更像封口 → 承 003 伏笔1（朝包厢摇头），加深“奉命单单捞他”。
5. **无限期留置·重点嫌疑人**：他被钉在顶层；调查结束后伙计身份与禁足规矩自然续上，无需另判 → 留置是壳，长期囚禁是实。
6. **工偿抵债**：打杂工钱先抵吃住，连正式围裙都不发 → 债务劳役，为日后“转正/赎身”留扣。
7. **全知背调**：“祖上三代都摸得清”“你想干什么我们比你知道得还早” → 回收 003 伏笔4（监控墙全知之眼）；全知即体贴，也即恐怖。
8. **谶语双钩**：姐姐“头一夜关门，第二夜……”、弟弟“山雨欲来风满楼”“自求多福” → 指向即将发生的大事，预言式钩子。
9. **“小屁”得名**：旧名死去、外号加身，与 002-004 产房重生同构；命名即落地，也为日后“真名”主题留扣。
10. **皂角气两处闭环**：手帕与被子同一气味 → “像家”的第一笔，为 006 家当/靓妈线铺垫。

**【旧伏笔回收情况】**

- 003 伏笔1（拦人后朝包厢摇头）→ 本集担保人继续奉命、处置过快，楼上操盘再加深（未完全回收，继续挂）。
- 003 伏笔4（监控墙全知）→ 热豆浆“祖上三代摸得清”，部分回收。
- 004 伏笔4（天赋之问）→ 龙凤胎反向给出“你身上有自己都不知道的东西”，形成对冲。
- 004 伏笔6（昏君死刑）→ 本集开场即承：死期将至、亲手摘王冠。
- 004 嚎啕大哭 → 本集清晨“小屁”之名正来自那场满楼皆闻的哭，产房谜面落地。

**【本集情绪曲线】** 刑场余波的不甘 → 手帕递来的一怔 → 姐姐恶语的刺 → 争执谶语的凉意 → 被架走的失重 → 留置手续里的木然 → 豆浆入口的烫（恍惚）→ 铁架床上的无眠 → 清晨“小屁”一喊，荒诞里透出一丝生趣。

**【集界与缺口】**

- 集界：005 起于刑场余波，止于清晨得名「小屁」；006 进入新人培训、家当（退房、靓妈电话）、菜单暗语。
- 待写/待揭：举报人/内鬼与调查结果；龙凤胎来历；科比布局真假；信封内容（003 遗物）。
- 严格走窒息流：内心收束极短不展开王国；大事由对话缝隙与背景动作带出，不做科普；龙凤胎保持旁观老客的分寸，不替幕后做解释。
