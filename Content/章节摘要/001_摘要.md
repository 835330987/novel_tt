# 001 第一集 · 速览

**【发生】** 输光一切的主角到龙门金阙寻死，随人流乘上只直达顶层的电梯；踏出电梯是悬空平台，被服务员用麻袋套过头（麻袋随即转套给另一名作呕客人，他才后知后觉），惊醒后被鲜红无护栏、直通红光的台阶摄住心神，无视身后呼唤，失神地一步步向上爬。

**【伏笔 · 待后文回收】**

1. 「闷响」=有人坠楼：曾与人打赌下一声闷响，如今轮到自己 → 回收点：主角最终跳没跳。
2. 顶层按键血红灯＋红阶尽头同一束红光 → 回收点：红光之上即天台（紧接下集）。
3. 「没有钢缆了，剩下的路自己走」→ 长线主题句，主角蜕变时回响。
4. 麻袋标准化套人（「做过三千遍」）、残着他人呕吐物 → 回收点：天台是流程化的收割流水线。
5. 母亲、三年未归、「坟头多摆一双筷子」→ 长线情感锚点与复仇动机。
6. 服务员之问「搞上去，还是搞回去」主角未口头回答 → 以爬红阶的行动作答，下集承接。

**【待收尾 / 缺口】**

- 按大纲，第一集尚缺：红阶尽头、镀金招牌「天台来帮您」、开门迎客、老炮出声拦下——待续写。
- 笔误待修：「我比谁都清楚涉嫌呕吐的下场」→「吐出来的下场」。
