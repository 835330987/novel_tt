# 004 第四集 · 速览（暂定名：小屁落地）

**【本集定位】** 003「求死不得的绞杀」的下半场，也是主角身份的落地章。黎明天台，停牌后「无处落脚的鸟」懵作一片；九二科比被人群簇拥上桌布道，核心只两个字——活下去。主角在布道声里从质疑大神，被一张张真实交割单逼到质疑自己（天赋之问）；心里那个还想封狼居胥的将军当庭被判死刑，随即一场信仰尽碎的嚎啕大哭（002 产房谜面在此揭底：大哭＝新生儿落地第一声啼哭）。最终他不是被恩义收留，而是被「举报留置＋缴不起留置费」逼成干活抵债的替补服务员——旧我死透，新我以「小屁」之名在最高处落地。**身份转换：赴死者 → 天台囚徒 / 替补伙计。**

**【发生】（情节节拍）**

**第一部分 · 黎明群像**

1. **灰青天台**：天是灰青色的，风过了一遍又一遍，「太平门」上的人却像都没觉着——他们和我一样，是停牌之后，无处落脚的鸟。
2. **懵态三动作**：有人靠围栏，眼直直望天尽头那一线白，像魂没从昨夜回来；有人顺墙根出溜下去，抱头抵膝；有人攥着手机，屏幕亮了又暗，手指悬在号码上，终究没拨出去。
3. **都愣住**：没人知道下一步往哪迈，这一夜之后还能往哪去。
4. **微光里的声音**：那一声声来自黎明时分的微光，裹在人群热气里，一声比一声亮；充满希望，充满幻想，无比温暖，像冻了一夜的人终于等来那一缕阳光。
5. **狰狞**：连绝望都懒得绝望的神情，此刻一齐变成抓住稻草的狰狞——那是对希望、对活下去的贪婪，是溺了一夜的人终于摸到岸。
6. **“有救了……有救了……”**
7. **脚先动**：脚迸发出求生欲，离开围栏，一步一步朝那圈人挪；等回过神，脸上早已挂上同款狰狞——妄想一夜回本的狰狞。

**第二部分 · 布道与质疑（现场与内心交替）**

8. **簇拥上桌**：众人七手八脚把科比簇拥上了桌子；他双手抬到胸前、掌心朝下不慌不忙压了压——球场老将压阵的手势（沉住气、落位、别急），满场声浪一寸寸矮下去。
9. **布道（真实语录为底，碎片呈现，不整段说教）**：
   - 开场：“我知道，你们里头，有些人在鬼门关前迈过腿”（他见过同样的人）；
   - 自述：也曾腰斩、腰斩、再腰斩，从死人堆里一步一步爬起来；
   - “草原上最不缺的是猎物，缺的是追猎物的命；你人没了，明早太阳照升、行情照走，一分一厘都跟你没关系了”；
   - “要谢就谢这场停牌——是它让你们捡回命，有了反悔的机会”；
   - 随风而来的其余碎片：复利一点一点滚／没有模式给一个亿也是韭菜／杠杆是催命的东西，我每年每月都吃天地大面／亏了那回就对自己撒手、由着身子出溜／金句“钱是挣不完的，命是亏得完的，活得久的，才叫赢家”。
10. **狰狞退去，先疑大神**：脸上的肉一松，退回惯常的自己——村口摇蒲扇的大妈都能说上三筐的话，怎么换个人、站上桌子，就成了真经，值得磕头？
11. **老祖病史**：拜过一个又一个老祖，战法交割单一张张捧过、抄过、供过，亲自试验，却成了韭菜炮灰；学来的语录把底气养得硬如铁——套住叫“格局”，跌破叫“黄金坑、磨意志”，就凭这份坚定不移一次次扛单，小坑扛成大坑，把亏损做到最大。
12. **迟到的质疑**：质疑为何总在最后一刻、等一切无法挽回、退无可退时，才肯降临。
13. **四种情绪**：行动时是希望与臆想盖住他，败后是麻痹、麻木与逃避盖住他——理性一寸立足之地都没有。
14. **从未复盘**：从没真正回头清点过战场，没学会在草原上走路，就直接去学老祖们攻城略地——越急越摔，越努力越往反方向跑。
15. **交割单转折**：可这一位的交割单是公开的，笔笔真账、坑坑真坑（进场出场、日子数目带着戳，连割肉都不藏）；我想挑个窟窿，一处也挑不出——那把质疑之矛，便从老祖身上缓缓指向自己。
16. **差距排比**：一样两条腿他能跑我也能跑，一样两只手他能投我也能投——人家是压哨绝杀，我是三不沾；谁不会划拉两笔字，有人成书法家，我的字贴门上辟邪；谁不会哼两句曲，有人成角儿，我一开口自家狗先夹尾巴。
17. **天赋之问**：就算科比关门弟子般倾囊相授（后仰怎么拧腰、出手怎么压腕、脚步怎么虚实），就算博尔特手把手校正姿势，九秒五八仍只他一人跑得出来——莫非真有天赋？莫非我天生就不是这块料？

**第三部分 · 裁决与大哭**

18. **将军死刑**：所有疑问似乎有了答案，我跪倒在众人面前，咸涩糊满脸，脑袋顺着泪滴埋进那一片红色符文——肉身从这场审判里活了下来，心里那个将军，却被判了死刑。
19. **嚎啕大哭**：信仰与信念一夜碎尽，哭声撕心裂肺、满楼皆闻（“小屁”之名的由来）。

**第四部分 · 留置与工偿**

20. **龙凤胎蹲地**：一对龙凤胎服务员凑到跟前，姐姐（恶魔）、弟弟（天使）一句交替，漏出信息——停牌系人为举报、上面正查内鬼；店长（值班掌柜）焦头烂额，把天台可疑人员排查数遍，最后留下几位，**你就是其中之一**；调查结束前，你们一步不得离开天台。
21. **上桌、饮品、介绍人**：被一左一右架起，请上台子上的椅子；一杯此生最爱、甜度温度都对的饮品递到面前（背调全知、管家式专业）；套他头又救他的那位服务生，正坐他对面——日后的介绍人/担保人（谁拽回来，谁负责带）。
22. **留置费与工偿**：白住白吃要自行承担（停牌让天台亏惨了，不开善堂）；他掏不出；对方向上请示后带回活路——干活抵债、打杂换饭：“劳改犯踩缝纫机还挣工钱呢”；他成了服务员里的替补，递毛巾、守饮水机的那个。
23. **肚子的死刑**：外面他已输光一切，不久要被自己的肚子宣判；而这里，今晚就有一口热的。
    （“不得离开顶层半步”的两层壳：明面是配合调查的留置，调查结束他已是拿饭吃的伙计，规矩自然续上，无需另判。）

**第五部分 · 入笼**

24. **宿舍无眠**：铁架上下铺，和衣倒床，一夜合不上眼；一闭眼就是悬空的脚、不紧不慢的猩红、母亲那句“家里都好，你别惦记”。
25. **神秘客人**：天快亮时围栏边，一位普通客人——“被服务生拉回来的，你是头一个；你身上有你自己都不知道的东西。好自为之。”
26. **小屁落地**：清晨被一把推醒，瘸腿大哥拍肩，嗓门满楼：“行了，小屁，别哭了，该上工了！”——爹妈给的名字自己都快记不清，这栋楼已替他起好了新名。（本集终）

**【主题与意象】**

- **002 产房谜面在本集揭底**：踩空（旧我咽气）→ 停牌（求死逻辑判死）→ 嚎哭（新我落地啼哭）。三段对位，全程不说破“重生”。
- **布道与生死暗通**：他讲“活下去、活得久”，主角听出的不是鼓舞，是照见——科比讥讽的“亏了就撒手、死活不管”的人，正是自己。
- **篮球意象贯穿全章**：压手手势、绝杀/三不沾、后仰、替补、守饮水机、博尔特九秒五八——科比之名的篮球底色被全面征用；博尔特一例后文还可复用。
- **气味与温度**：清鲜气扑空（烟酒味、利好皆臆想）之后，他没等来救赎的气味，只等来一杯记着他口味的热饮——全知即体贴，也即恐怖。
- **核心反讽**：他刚想到“收手、过另一种生活”，另一种生活就在原地、以囚徒和替补的身份开始；逃了一辈子爬上最高处，结果被永久挂在最高处。

**【核心伏笔 · 待后文回收】**

1. **举报内鬼之谜**（新增）：谁举报、为何举报，店长排查留置——长线悬疑；回收点：调查结果、内鬼真身。
2. **“单独为一个人设计的停牌”**：恶魔“你也配，停牌为更大的鱼”／天使“千万人里单留你，不是巧合”——他究竟是被选中的人，还是巨人棋局里的虾米，长线总悬念。
3. 拦人后朝顶层包厢摇头（003）＋留置工偿处置过快 → 楼上有人操盘，他一路被推着走。
4. **龙凤胎自述**：皆为被碾碎后留下的人，一个把心练成铁、一个泡成水——主角未来两条路的镜像。
5. 神秘客人“你身上有自己不知道的东西”——天赋绝望的反向钩子，长线。
6. 套头服务生＝介绍人/担保人：罩黑世界的手，变成管他的手——师徒与灰度线。
7. “小屁”命名＝旧身份死亡，与产房重生同构；留置费/工偿＝债务劳役，为日后“转正/赎身”留扣。

**【本集情绪曲线】** 懵住 → 被声音点燃的狂热狰狞 → 布道声中冷静 → 疑神 → 疑己 → 差距与天赋的凉 → 将军死刑 → 嚎啕释放 → 留置恐惧与饥饿 → 一杯热饮的恍惚 → 无眠 → 神秘客悬念 → 小屁命名，荒诞里透出一丝生趣。

**【待拍板 / 缺口】**

1. 龙凤胎身份：工作人员，还是半客半工的“老人”？**建议后者**（没资格谈规矩，只能漏真话）。
2. “单独为一个人”的谜底方向：冲他来，还是冲大鱼、他只是顺带？决定长线宿命感。
3. 最爱饮品：沿用热豆浆，还是换一款廉价汽水（落魄之前的甜）？
4. 收留节奏：当场木然应下，还是拖到次日清晨？**建议当场**（他已无力还价）。
5. 替补名目：发“见习服务生”旧围裙，还是什么都不给？**建议什么都不给**（连正式收编都不配，为“转正”留写点）。
6. 早先“走廊夜里偷听举报”一段并入龙凤胎台词（夜里只保留失眠），避免重复——建议并入。
7. “你想跳楼，我们比你知道得还早”一句是否保留？
8. 布道正文呈现：碎片随风（建议），还是完整五段；严格走窒息流，规则由对话带出，不做科普，不实体拟人、不白描功能。
