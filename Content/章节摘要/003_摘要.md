# 003 第三集 · 速览（暂定名：想死都难）

**【本集定位】** 一次「求死不得」的全程绞杀。002 结尾他踩空、产房错觉（旧我将死、新我将生），003 开篇他已在「太平门」断口边缘，被一只手从虚空里硬生生倒拔回来。被拽回只是第一层；随后停牌封死所有窗口、「跳了等于给仇人送钱」的规矩浮上来，把他「以死尽孝」的逻辑一层层拆毁。他被像物件一样扔进后场安保室，又凭一口气摸上天台，正撞上停牌后无处落脚的人群认出游资大佬九二科比、喊出「有救了」——本集在人群抓住救命稻草的一刻收住。

**【发生】（情节节拍）**

1. **边缘恍惚**：接 002 踩空——惨白的灯、开合的铁门、推车、消毒水味；时间像一束烟花炸开，一张张脸拖成残影，光溢满眼窝、顺着脸颊淌。啼哭般的唢呐声不肯收，风先醒，石阶的棱正把脚心往外推：他已站在断口最边处。
2. **一把拽回**：一只手猛扣胳膊，小臂横上喉结，两条腿跨腰锁成三角，他被掼回「太平门」。来人喘得像破风箱，是 001 电梯外抖麻袋、把他世界罩黑的那张脸，连声道歉：“喊了你几百万次，你都没理。”
3. **拖回人间**：地砖的凉诡异地翻成灼痛，他被蛮力向后拖行，一寸寸蹭过地面，从「太平门」里硬生生拽回。
4. **怒问“为什么是我”**：他只想把一生这张薄纸轻轻合上——满断口那么多人，唯独伸向他的手把他拉回，倒像他才是不守规矩的人。“我这辈子从没这样清醒过。”这声错音撕开端庄大厅，客人逐桌噤声，刀叉悬着，全围过来看戏。
5. **归还遗物**：服务生掏出他在电梯外「落客台」摔落的两样东西——一部手机、一个信封。他一把抓过又往断口走，对方再拦，凑耳边密报：窗口将有异象，再等两刻钟，那笔补偿金能多出一截。
6. **停牌**：红马甲女经理人分开众人，高声宣布：触发异常风险提示、停牌调查，「太平门」所有窗口即刻关闭。他以旁观者的耐心听完，脑中情绪一片空白，某个至关重要的结论将触到，又被自我保护本能挪开；紧拽他的手随一声长舒松开，服务生朝顶层包厢望了一眼，极轻地摇头。
7. **松手诛心**：服务生退一步，挤出没有温度的笑：“行，你去吧，不拦你了，你去死吧。”他僵在原地——停牌后强行触发交易，补偿金一分没有，还要倒交罚款，跳下去等于给这辈子最恨的人送钱。这种蠢事，他绝对不干。**求死的逻辑，到此死透。**
8. **扔进安保室**：红马甲抬手一挥，两位服务员一左一右把他架起，像清理一件碍脚的物件，半拖半架，丢进后场某个角落的杂物堆。
9. **安保室所见**：迎面几十个数格子塞满了人，每格左上角存着时间与编号（凌晨四点）；两张细长桌子贴墙分居两侧，包、水壶、外套摞在桌上挤作一堆；左侧墙嵌一整面玻璃，门就在玻璃旁边，外头情形看得清清楚楚。
10. **忙碌味与盒饭**：空气里漂浮着一股名为忙碌的复杂气味，算不上难闻，却令人窒息、令人作呕；机器散出的热气逼人，他撑桌站起想往外走，迷糊中撞上桌角吃剩一半的盒饭——微生物忙碌啃食大半天的酸馊味，这才漫开。
11. **清鲜气扑空**：玻璃外那一口冒着光的清鲜气勾人，鼻尖不知不觉贴上玻璃；他撞门跨出去，口鼻用力一吸，扑来的却是浓重烟酒味。他笑出了声：门外哪有什么清鲜气，一切利好，全源自大脑里的臆想。
12. **围栏换气**：他贴着围栏走到风大处站住，张大嘴，想把肺里那股疲劳一口一口换掉。风是好东西，一口下去，人总算还像是个活人。
13. **科比到来**：身后灯光暗了一角，人群一撮撮往一处凑。“科……比……”起先生涩零碎，东一声西一声；后来名字被谁咬实，零碎拧成一股，越来越齐、越来越亮：“科比！是科比！九二科比！”
14. **群像**：前排伸着脖子眼不敢眨，怕漏一处细节；心急的挤在缝里踮脚，一手小本一手笔，想抄走的不止翻身口诀，还有悟道、和那串明早就能让亏损清零的神秘代码；上年纪的腿一软双膝跪倒，额头一点一点朝灯底下那个人，念念有词。
15. **集末**：“是科比！是九二科比！有救了！俺们有救了！”——悬念挂在大师现身、满场人抓住稻草的一刻。

**【主题与意象】**

- 本集闭环的是「绞杀」：求死的路被逐一封死——拽回（身不由己）→ 停牌（窗口尽失）→ 罚款规矩（跳了反而害人害己、成全仇人）。他不是被劝活的，是被规则逼得死不成。
- 002 的产房谜面在本集只走到「啼哭/唢呐」与边缘风醒，**大哭这一「新生儿第一声啼哭」的揭底留给 004**，写作时仍不说破「重生」。
- 气味驱动动作的一条感官线：忙碌味（窒息）→ 盒饭馊味（迷糊）→ 清鲜气（勾人）→ 烟酒味（扑空）。「一切利好全是大脑臆想」为主角反复出现的自我警惕定调，也呼应他此前拜过无数「老祖」、却把死扛当格局的病史。
- 人群即自照：停牌后无处落脚的鸟、伸脖子的、跪地的、要神秘代码的——他日后在 004 会意识到自己与他们是一路人。

**【核心伏笔 · 待后文回收】**

1. 服务生拦人后朝顶层包厢望一眼、轻轻摇头 → 奉命而非善心，他被选中不是偶然。回收点：楼上操盘者、老板娘为何留他。
2. 兜头麻袋男（001）的手第一次反向用力：从罩黑世界的手，变成拽回人间的手 → 服务生阵营灰度埋线。
3. 归还的手机与信封 → 遗物与家人线，信封内容待揭；他寻死的全部理由是母亲，拦住他死的理由仍将是母亲。
4. 监控墙几十格、凌晨四点、时间编号 → 楼里的全知之眼，为「你想跳楼我们比你知道得还早」（004）蓄势。
5. 九二科比登场：落脚飘忽、传闻纷纭、布道核心「活下去、活得久」→ 004 正面展开，与天台生死抉择暗通。
6. 「停牌／窗口／补偿金／强行触发倒交罚款」规则首次落地 → 坐实天台即市场，为复牌、价码后文铺路。

**【本集情绪曲线】** 断口恍惚 → 被拽回的惊怒 → “为什么偏偏是我”的疑 → 停牌的空白与失重 → “你去死吧”的诛心 → 被丢弃的窝囊 → 忙碌味里的窒息 → 清鲜气扑空的自嘲 → 风中片刻还魂 → 科比声起、满场狂热，他立于旁观与被卷入之间。

**【集界与缺口】**

- 集界已定：003 止于「有救了」；004 起于黎明微光中打转的那三个字，经落泪、布道、收留、宿舍、举报传闻、神秘客人，到清晨得名「小屁」。
- 早先的「492」编号已取消，监控屏只保留时间（凌晨四点）。
- 待写/待揭：布道内容与主角的自我照见（004）；信封里是什么；科比今夜为何在此（三条传闻，004）。
- 严格走窒息流：停牌冲击交给身体，规则由对话与围观带出，不做设定科普；不实体拟人、不白描功能，只写眼睛看到的画面与鼻子闻到的气味。
